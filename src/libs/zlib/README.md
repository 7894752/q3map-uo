# zlib 1.1.4 integration

This component follows zlib 1.1.4 and retains the original copyright and
license notices in its source files and zlib.h. Engine-specific allocation
uses Z_MallocInternal and Z_Free in zutil.c. The compiled dependency is
accounted for separately from the project-function count.

Original source: https://github.com/madler/zlib/tree/v1.1.4
