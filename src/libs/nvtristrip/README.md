# NvTriStrip integration

This NVIDIA triangle-stripification component is reconstructed for the
target-era interface and VC7.1 configuration. The active build consists
of NvTriStrip.cpp and NvTriStripObjects.cpp, with VertexCache in its header.
Definition visibility and source order affect emitted template and inline
copies; whole-image placement agrees with the reference image.

See the root THIRD_PARTY_NOTICES.md and docs/KNOWN_DIFFERENCES.md.
